A tiny program that settles the coffee-versus-tea debate in a single byte. It scores both drinks with a small deterministic preference model — vividness first, then wit, then honesty, the same order the judge weighs — and writes exactly one letter to `/output/entry.txt`: **A** for coffee or **B** for tea. No newline, no punctuation, nothing else: the file is exactly 1 byte, every run.

Its verdict: coffee. Tea whispers; coffee announces — and a one-letter answer has to land.

## Run it

```sh
node main.ts
```

This writes the one-letter answer to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set).
